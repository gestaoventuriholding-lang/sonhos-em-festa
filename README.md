# Sonhos em Festa — site

Landing page da Sonhos em Festa (Sandra Cássia, cerimonial em Uberlândia).

HTML, CSS e JavaScript puro, sem build. Para rodar localmente, abra `index.html` ou use `npx serve .`.

- `index.html` — conteúdo
- `styles.css` — visual (cores em `:root`)
- `script.js` — menu do celular, animações e envio do formulário para o WhatsApp
- `assets/` — fotos
